# Эмулятор оболочки ОС (вариант 1)

## Общее описание

Эмулятор командной строки UNIX-подобной ОС на Python 3.8+ (только
стандартная библиотека). Реализованы этапы:

1. REPL — диалог с пользователем, парсер с кавычками, обработка ошибок,
   команды-заглушки (с этапа 4 `ls` и `cd` — полноценные команды);
2. Конфигурация — параметры командной строки, стартовый скрипт и
   отладочный вывод всех параметров;
3. VFS — виртуальная файловая система, загружаемая из JSON-файла и
   целиком хранящаяся в памяти;
4. Основные команды — `ls`, `cd`, `pwd`, `history`, `tail`, работающие
   с VFS как с настоящей файловой системой UNIX.

## Функции и настройки

### Параметры командной строки

| Параметр        | Описание                                           |
|-----------------|----------------------------------------------------|
| `--vfs ПУТЬ`    | JSON-файл с виртуальной файловой системой          |
| `--script ПУТЬ` | путь к стартовому скрипту с командами эмулятора    |
| `-h`, `--help`  | справка по параметрам                              |

При запуске эмулятор печатает все заданные параметры (незаданные
помечаются `(не задан)`), а после загрузки VFS — её краткую сводку:

```
[отладка] Параметры запуска:
[отладка]   script = examples/vfs_check.txt
[отладка]   vfs = examples/vfs/deep.json
[отладка] VFS загружена: каталогов: 5, файлов: 4
```

Коды возврата при ошибках запуска:

| Код | Причина                                                        |
|-----|----------------------------------------------------------------|
| 2   | неизвестный параметр, параметр без значения, нечитаемый скрипт |
| 3   | ошибка загрузки VFS                                            |

### Виртуальная файловая система

Источник VFS — JSON-файл. Все операции выполняются в памяти: данные VFS
не распаковываются на диск и не изменяются. Корень — каталог:

```json
{
  "type": "dir",
  "children": {
    "readme.txt": {"type": "file", "content": "текст"},
    "logo.bin": {"type": "file", "encoding": "base64", "content": "AAEC"},
    "docs": {"type": "dir", "children": {}}
  }
}
```

- `type` — `dir` (каталог) или `file` (файл);
- `children` — объект «имя → узел» (для каталога, по умолчанию пустой);
- `encoding` — `text` (по умолчанию, UTF-8) или `base64` для двоичных
  данных; `content` — строка (для файла, по умолчанию пустая);
- имена не должны быть пустыми, `.`/`..` или содержать `/`.

Ошибки загрузки (печатаются в stderr, код возврата 3): файл не найден,
неверный формат JSON, неверная структура (неизвестный тип узла, корень не
каталог, недопустимое имя), неверные данные base64, файл нельзя прочитать.

Примеры VFS лежат в `examples/vfs/`: `minimal.json` (пустая),
`several.json` (несколько файлов, в том числе двоичный), `deep.json`
(четыре уровня вложенности), `stage4.json` (скрытые файлы, файл из
15 строк, файл без перевода строки, двоичный файл, пустой каталог), а
также `bad_*.json` для проверки ошибок.

### Стартовый скрипт

Текстовый файл (UTF-8), по одной команде эмулятора в строке:

- команды выполняются последовательно;
- на экран выводится и ввод (приглашение и команда), и вывод, как в диалоге
  с пользователем;
- ошибочные строки (неизвестная команда, неверные аргументы, незакрытая
  кавычка) печатают сообщение об ошибке и пропускаются;
- пустые строки и строки, начинающиеся с `#`, игнорируются;
- `exit` в скрипте завершает эмулятор; без него после скрипта начинается
  интерактивный режим.

### Интерактивный режим и команды

- Приглашение `username@hostname:/путь$` формируется из реальных данных ОС
  (`getpass.getuser()`, `socket.gethostname()`) и текущего каталога VFS;
  в корне оно имеет вид `username@hostname:/$`.
- Парсер: аргументы разделяются пробелами; поддерживаются `"двойные"`
  (с экранированием `\"` и `\`) и `'одинарные'` кавычки, `\` вне кавычек,
  пустой аргумент `""`.
- Ошибки (печатаются в stderr, работа продолжается): неизвестная команда,
  незакрытая кавычка, неверные аргументы.
- Команды описаны ниже; `Ctrl+D` и `Ctrl+C` — см. в конце раздела.

#### Текущий каталог и пути

Корень VFS — каталог `/`, с него начинается работа. Пути бывают
абсолютными (`/home/user`) и относительными к текущему каталогу
(`docs/report.txt`); поддерживаются `.`, `..` и повторные `/`.
`..` в корне остаётся в корне. Без `--vfs` используется пустой корень
в памяти. Все изменения касаются только состояния сеанса (текущий каталог
и история), содержимое VFS не меняется.

#### `ls [-a] [-l] [-r] [путь...]`

Выводит содержимое каталога (по умолчанию — текущего) по одному имени в
строке, отсортированное по имени. Для пути к файлу выводит его имя.

| Режим  | Действие                                                    |
|--------|-------------------------------------------------------------|
| `-a`   | показать скрытые имена (начинаются с `.`), `.` и `..`       |
| `-l`   | длинный формат: тип (`d`/`-`), размер в байтах и имя        |
| `-r`   | обратный порядок                                            |
| `-la`  | флаги можно объединять; `--` завершает список опций         |

Несколько путей: сначала файлы, затем каталоги с заголовками `путь:`.
Если часть путей не найдена, для остальных вывод сохраняется, а об ошибках
сообщается отдельно.

#### `cd [путь | -]`

Меняет текущий каталог. `cd` без аргумента переходит в корень, `cd -` —
в предыдущий каталог (и печатает его путь). Ошибки: каталог не найден,
путь указывает на файл, лишние аргументы, неизвестная опция.

#### `pwd [-L] [-P]`

Печатает абсолютный путь текущего каталога. Опции `-L` и `-P`
принимаются для совместимости (символических ссылок в VFS нет).

#### `history [N | -c]`

| Вызов        | Действие                                              |
|--------------|-------------------------------------------------------|
| `history`    | вся история с номерами (как в bash)                   |
| `history N`  | последние `N` записей (`history 0` ничего не печатает) |
| `history -c` | очистить историю, нумерация начинается заново         |

В историю попадают все непустые введённые строки, в том числе ошибочные,
команды из стартового скрипта и сама команда `history`.

#### `tail [-n N | -N] [-c N] [-q | -v] файл...`

Выводит конец файлов VFS.

| Режим       | Действие                                                 |
|-------------|----------------------------------------------------------|
| без опций   | последние 10 строк                                       |
| `-n N`, `-nN`, `-N` | последние `N` строк                              |
| `-n +N`     | строки, начиная с `N`-й                                  |
| `-c N`      | последние `N` байтов (`-c +N` — начиная с `N`-го)        |
| `-q`, `-v`  | никогда / всегда печатать заголовки `==> имя <==`        |

Заголовки по умолчанию печатаются при нескольких файлах. Двоичные данные
декодируются как UTF-8 с заменой неверных байтов. Чтение со стандартного
ввода не поддерживается: без файла команда сообщает об ошибке. Ошибки:
файл не найден, указан каталог, неверное число, неизвестная опция.

#### Остальные команды

- `exit [код]` — завершение работы с кодом возврата (по умолчанию 0);
- `vfs-info` — служебная команда: источник, число каталогов и файлов,
  размер данных и глубина VFS;
- `vfs-tree` — служебная команда: дерево каталогов и файлов VFS.
  Обе служебные команды без `--vfs` сообщают об ошибке и не принимают
  аргументы.
- Ошибки (неизвестная команда, неверные аргументы, незакрытая кавычка)
  печатаются в stderr с префиксом `ошибка:`, работа продолжается.
- `Ctrl+D` (конец ввода) также завершает работу, `Ctrl+C` отменяет строку.

## Сборка, запуск и тесты

```
./run.sh [параметры]          # Linux/macOS
run.bat [параметры]           # Windows
make run ARGS="--vfs examples/vfs/deep.json"
make test                     # модульные тесты
```

Тесты без Makefile: `PYTHONPATH=src python -m unittest discover -s tests`.

Скрипты ОС для проверки (папка `scripts/`, по паре `.sh` / `.bat`):

| Скрипт                | Что проверяет                                       |
|-----------------------|-----------------------------------------------------|
| `test_vfs`            | параметр `--vfs`                                    |
| `test_script`         | параметр `--script` (выполнение скрипта с эхом)     |
| `test_all`            | оба параметра вместе                                |
| `test_errors`         | ошибки параметров командной строки                  |
| `test_vfs_variants`   | VFS: минимальная, несколько файлов, 3+ уровня (скрипт) |
| `test_vfs_stdin`      | те же варианты VFS при вводе из stdin               |
| `test_vfs_errors`     | ошибки загрузки VFS и коды возврата                 |
| `test_full_demo`      | стартовый скрипт этапов 1–3: с VFS и без неё        |
| `test_stage4`         | стартовый скрипт этапа 4: три варианта VFS и без VFS |

```
sh scripts/test_stage4.sh     # Linux/macOS
scripts\test_stage4.bat       # Windows
make check-scripts            # все .sh-скрипты подряд
```

## Примеры использования

```
$ ./run.sh --vfs examples/vfs/deep.json
[отладка] Параметры запуска:
[отладка]   script = (не задан)
[отладка]   vfs = examples/vfs/deep.json
[отладка] VFS загружена: каталогов: 5, файлов: 4
user@host:/$ vfs-tree
/
|-- etc/
|   `-- hosts
|-- home/
|   `-- user/
|       |-- docs/
|       |   |-- data.bin
|       |   `-- report.txt
|       `-- todo.txt
`-- tmp/
user@host:/$ cd home/user
user@host:/home/user$ pwd
/home/user
user@host:/home/user$ ls -l
d        0 docs
-       25 todo.txt
user@host:/home/user$ tail -n 1 todo.txt
купить молоко
user@host:/home/user$ cd missing
ошибка: cd: missing: нет такого файла или каталога
user@host:/home/user$ history 3
    5  tail -n 1 todo.txt
    6  cd missing
    7  history 3
user@host:/home/user$ exit
```

```
$ ./run.sh --vfs examples/vfs/missing.json
ошибка: не удалось загрузить VFS: файл не найден: examples/vfs/missing.json
```

Стартовый скрипт этапа 4 со всеми режимами `ls`, `cd`, `pwd`, `history`,
`tail`, работой с VFS и ошибками:
`./run.sh --vfs examples/vfs/stage4.json --script examples/stage4.txt`.

Команды этапов 1–3 и ошибки:
`./run.sh --vfs examples/vfs/deep.json --script examples/full_demo.txt`.

## Структура

- `src/shell_emulator/cli.py` — запуск: параметры, VFS, скрипт, REPL;
- `src/shell_emulator/config.py` — параметры командной строки и отладка;
- `src/shell_emulator/vfs.py` — загрузка и разбор VFS из JSON, поиск узлов;
- `src/shell_emulator/paths.py` — нормализация путей VFS;
- `src/shell_emulator/session.py` — состояние сеанса (VFS, каталог, история);
- `src/shell_emulator/options.py` — разбор коротких опций команд;
- `src/shell_emulator/fs_commands.py` — команды `ls`, `cd`, `pwd`;
- `src/shell_emulator/history.py` — команда `history`;
- `src/shell_emulator/tail.py` — команда `tail`;
- `src/shell_emulator/errors.py` — исключения команд;
- `src/shell_emulator/script.py` — стартовый скрипт;
- `src/shell_emulator/parser.py` — разбор строки;
- `src/shell_emulator/commands.py` — реестр команд, `exit`, `vfs-*`;
- `src/shell_emulator/repl.py` — интерактивный цикл;
- `tests/` — модульные тесты; `scripts/` — скрипты ОС для проверки;
  `examples/` — скрипты эмулятора и примеры VFS.
