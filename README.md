# Эмулятор оболочки ОС (вариант 1)

## Общее описание

Эмулятор командной строки UNIX-подобной ОС на Python 3.8+ (только
стандартная библиотека). Реализован этап 1 — REPL: диалог с пользователем,
парсер с кавычками, обработка ошибок и команды-заглушки.

## Функции и настройки

- Приглашение `username@hostname:~$` формируется из реальных данных ОС
  (`getpass.getuser()`, `socket.gethostname()`).
- Парсер: аргументы разделяются пробелами; поддерживаются `"двойные"`
  (с экранированием `\"` и `\`) и `'одинарные'` кавычки, `\` вне кавычек,
  пустой аргумент `""`.
- Ошибки (печатаются в stderr, работа продолжается): неизвестная команда,
  незакрытая кавычка, неверные аргументы.
- Команды:
  - `ls [args...]` — заглушка, выводит своё имя и аргументы;
  - `cd [dir]` — заглушка, выводит своё имя и аргумент (больше одного
    аргумента — ошибка);
  - `exit [код]` — завершение работы с кодом возврата (по умолчанию 0).
- `Ctrl+D` (конец ввода) также завершает работу, `Ctrl+C` отменяет строку.

Настроек пока нет (появятся на этапе 2).

## Сборка, запуск и тесты

```
./run.sh            # Linux/macOS
run.bat             # Windows
make run            # через Makefile
make test           # тесты (или: PYTHONPATH=src python -m unittest discover -s tests)
```

Демонстрация всей функциональности:

```
PYTHONPATH=src python -m shell_emulator < examples/demo.txt
```

## Примеры использования

```
user@host:~$ ls -l "my folder" file.txt
ls -l my folder file.txt
user@host:~$ cd /home/user
cd /home/user
user@host:~$ foo
ошибка: foo: команда не найдена
user@host:~$ cd a b
ошибка: cd: слишком много аргументов
user@host:~$ ls "unclosed
ошибка: незакрытая двойная кавычка
user@host:~$ exit abc
ошибка: exit: abc: требуется числовой аргумент
user@host:~$ exit
```

## Структура

- `src/shell_emulator/parser.py` — разбор строки;
- `src/shell_emulator/commands.py` — команды;
- `src/shell_emulator/repl.py` — интерактивный цикл;
- `tests/` — модульные тесты; `examples/` — демонстрационный ввод.
